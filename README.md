Expense Tracker Web Application
        A React-based Expense Tracker web application that allows users to manage income and expenses with real-time balance calculation and LocalStorage data persistence.
        

Features
- Add income and expense transactions
- Automatically calculates total income, total expenses, and balance
- Delete transactions
- Data stored using LocalStorage (persists after refresh)
- Clean and responsive UI
- 

Technologies Used
- React JS
- Vite
- HTML5
- CSS3 / Tailwind CSS
- JavaScript / TypeScript


How to Run the Project
1. Clone the repository
2. Open terminal inside the project folder
3. Run:

```
npm install
npm run dev
```
Open browser at:
```
http://localhost:5173/
```
